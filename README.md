GreenLight Calculator เป็นเว็บแอปพลิเคชันสำหรับคำนวณค่า DLI (Daily Light Integral) 
ที่พืชได้รับภายในโรงเรือน โดยประยุกต์ใช้ตรีโกณมิติของมุมแหลมและเรขาคณิตวิเคราะห์ 
ในการวิเคราะห์รูปทรงหลังคา 11 แบบ ร่วมกับวัสดุมุงหลังคา 6 ชนิด และฐานข้อมูลพืช 73 ชนิด 
ครอบคลุม 12 จังหวัดตัวแทนของประเทศไทย

พัฒนาโดยทีมนักเรียนชั้นมัธยมศึกษาปีที่ 3 สำหรับโครงงานคณิตศาสตร์ระดับประเทศ 
ครั้งที่ 11 ปีการศึกษา 2569 (รอบชิงชนะเลิศ จุฬาลงกรณ์มหาวิทยาลัย)

หัวข้อ: การประยุกต์ตรีโกณมิติและเรขาคณิตวิเคราะห์ในการออกแบบหลังคาโรงเรือนปลูกพืช
